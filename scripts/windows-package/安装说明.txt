AgentLink · Windows 预览版
===========================

日常只打开 AgentLink。窗口显示“这台电脑已就绪”后，已配对的其他电脑
可以使用这台 Windows。关闭窗口后应用仍在通知区域运行。

要从 Windows 主动连接其他电脑：先在对方的 AgentLink 点“允许新电脑连接”，
再在本应用点“添加电脑”，从列表选它并点“连接”。如果列表没有显示，
输入对方的局域网 IP。最后在对方电脑确认请求。配对成功后不必重复操作。

要让其他电脑连接本机：在本应用点“允许别人连接”，再到对方电脑点
“添加电脑”。本机会弹出确认框；认得请求方才点“是”。

键鼠共享：Windows 窗口点“配置键鼠共享”准备本机辅助程序。就绪后，
同一位置的按钮会变成“设置屏幕位置”，可设 Mac 在 Windows 的左、右、
上、下；不设置则跟随 Mac 端的位置。在 Mac 的 AgentLink 点“开启共享”
后，鼠标推到边缘即可跨屏，键盘跟随鼠标。紧急停止按
Control+Alt+Esc。若 Windows 端尚未就绪，窗口会引导配置辅助程序；
配置后需要重新启动 AgentLink 服务才会生效。

窗口里的“已保存配对授权”是历史授权记录数，不是此刻在线的电脑数。
同一台 Mac 重复配对会留下多条记录；程序不会自动删除旧授权。

想让它在 Windows 登录后自动上线：在应用中点一次“开机自动连接”。
旧版 AgentLink 启动快捷方式会移入用户目录下的 .agentlink-node\Backups，
不会被删除。移动或升级本文件夹后，应检查开机项是否仍指向有效路径。

本包自带 Node 运行时。请保留 AgentLink.exe 和 runtime 文件夹在一起，
不用安装 Node，也不用打开命令窗口。配对身份和授权保存在当前用户目录，
不放在安装包中。

如果显示“服务未就绪”，点“检查并启动服务”；仍失败时先确认旧版没有
占用端口，再查看本机防火墙和局域网连通性。不要为了连接而关闭证书验证。

本版把日常启动、双向配对、跨屏位置和登录自启放进一个应用。
现有配对资料保持不变。
