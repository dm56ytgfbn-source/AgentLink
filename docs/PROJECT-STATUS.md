## rc.8 界面修复

Windows 配对 JSON 数组被原生界面按错误类型读取，造成已配对设备显示为 0、键鼠共享目标为空。rc.8 修复读取，已配对项改为验证原有连接，并在 Windows 原生自测中加入真实解析回归。已在 Windows 热修复窗口确认显示配对设备、启动与另一台 Windows 的共享；实体键鼠跨屏仍需用户验收。[修复说明](releases/v0.1.0-rc.8.md)。

## 当前优先项

rc.7 正补齐 Windows 主动键鼠共享：单窗口选择目标/位置/启停、按真实操作系统转发按键、原生独占保护。已完成 Windows 编译及本地透传链路测试；两台 Windows 实体跨屏尚未验收，不能标为完成。详见 [rc.7 记录](releases/v0.1.0-rc.7.md)。

## 不可省略的后续验收

新用户在干净机器完成下载、安装、配对、执行一个任务、重启再使用；两台 Windows 双向发现与手动 IP 连接；切换网络/IP 后恢复；旧启动项与旧后台检测/协调迁移且保留身份；输入共享中断后的本地控制恢复。

10 月 4 日 Windows 三个进程工作集约 164.7 MiB 仅为一次历史快照，不是当前平均内存或优化后的数据。后续在固定场景测量窗口打开/关闭、键鼠开关、2/4 设备的所有进程工作集与空闲 CPU。

旧验收记录仅用作证据，不把模拟测试、CI 或一次安装成功表述为完整支持矩阵通过。
