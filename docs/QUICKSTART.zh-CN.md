# AgentLink 新用户指南

## 下载与安装

只从 [GitHub Releases](https://github.com/dm56ytgfbn-source/AgentLink/releases) 下载 `.exe`（Windows x64）或 `.dmg`（M 系列 Mac）。不需要 GitHub 账号，不需要下载 Source code。当前为未签名预览版，系统可能提示或阻止运行；尚非零门槛的正式签名安装版。

Windows 安装时需要一次管理员确认，以准备安装目录和仅限本地子网的防火墙规则。Mac 把应用拖入“应用程序”再打开。不要同时启动历史桌面副本。更新保留原有配对配置；如果提示后台版本不一致，先正常退出旧版 AgentLink，再打开安装版，不必重新配对或删除数据。

## 连接另一台电脑

1. 两台电脑开机、登录并打开 AgentLink。连接到可以互相访问的局域网。
2. 在接收端开放新连接。Windows 按钮为“允许别人连接”；Mac 在接收端设置中启动接收服务并开放配对。
3. 在发起端添加电脑：Windows 为“添加电脑”，Mac 为“连接新电脑”。选择对方或输入局域网 IP。
4. 在接收端核对请求并确认。开放配对是限时的；过期后重新开放即可。

“已配对”表示保存了连接身份，不代表对方正在在线。“本机已就绪”表示本机服务在工作，也不代表其他电脑在线。rc.5 的 Windows 界面尚存在将配对数标成连接数的问题，开发版 rc.6 已修正文案。

## 交给 Agent 使用

配对电脑与配置 Agent 是两步。按应用内接入引导为你使用的 MCP 客户端配置 AgentLink，然后让 Agent 查看电脑列表并选定目标。例如：“通过 AgentLink，在我的 Windows 电脑上查看已安装的应用。”

Agent 自身的操作批准规则由对应客户端控制，AgentLink 不会绕过它。不同系统可用工具可能不同，应以目标电脑返回的能力为准。

## 共享键鼠

目前先以两台 Mac / Windows 混合设备测试。启用键鼠共享，按实际桌面摆放设置屏幕位置。Mac 需要辅助功能与输入监控权限；系统验证由电脑主人完成。键盘跟随当前输入所在设备。按 Control + Option + Esc（Windows 为 Ctrl + Alt + Esc）可停止共享。

同系统组合和三四台设备布局尚未完成全面验收，不能仅依据配对成功判断键鼠支持已完善。

## 找不到或连不上

| 现象 | 先检查 |
| --- | --- |
| 列表里没有对方 | 两台都打开服务；重试扫描；输入对方局域网 IP |
| IP 能连接，但列表没有 | 自动发现使用 UDP 47823，可能被网卡路由、Wi-Fi 或防火墙限制 |
| 输入 IP 也失败 | 检查对方服务、当前 IP、TCP 7443、访客 Wi-Fi / 公司网络隔离 |
| 能发现但不能配对 | 对方需重新开放配对，并在有效时间内确认 |
| 安装新版后还是旧版 | 正常退出旧版 AgentLink，从系统安装目录打开；保留配对数据 |
| 本机发现报端口占用或权限错误 | 按错误检查 UDP 47823；直接 IP 可绕开发现，但不能绕过 TCP 阻断 |

Windows 安装器配置本地子网范围的 TCP 7443 / UDP 47823 入站规则。无需关闭整个防火墙或路由器端口映射。组织网络策略可能覆盖本机规则；公司 Wi-Fi 禁止电脑互访时，需要管理员协助。开发版的发现修复不保证解决所有网络隔离问题。

反馈请附上两端版本、系统、错误文字，以及“自动发现”和“输入 IP”各自的结果。不要发送令牌、私钥或配对 JSON。
