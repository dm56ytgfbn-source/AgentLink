# AgentLink 当前验收说明

更新于 2026-09-15。版本为 0.1.0-rc.1，当前是局域网候选版。

## 本轮已经跑通

- 两端切换到新证书，Windows 服务不再绑定旧 IP。Mac 插件、命令行和原生查看器使用同一份配对配置。
- Windows 登录启动入口已更新；实测停止 AgentLink 服务后，监督进程会启动新进程，长任务记录保留。
- Mac 文件挂载读写与 Windows 实际文件内容一致，服务恢复后仍可读取。
- 修复了“不存在的文件被报告成空文件”的问题。实际挂载的新建排他文件测试通过，重复创建不会覆盖原内容。
- 原生查看器已显示 Windows 记事本单窗口。通过查看器输入文字、点击保存后，Windows 文件读回验证通过。
- 本地 15 项运行时回归通过。Windows 新目录安装依赖后，15 项中 14 项通过、1 项平台相关用例跳过；最终文件修复的受影响测试又在 Windows 通过。

## 你现在怎么检查

打开原项目文件夹里的“Mac-打开Windows应用.command”，入口已指向新版查看器。当前已打开专门的记事本验收文件，可以查看画面和尝试选择应用。

Mac 文件路径继续使用 `~/AgentLink/RTX-PC`。Agent 的本机终端仍在 Mac；通过 `computer_exec` 执行的命令在 Windows，较长工作可用 `computer_task_submit`。

## 还没有完成的验收

完整电脑重启、退出登录、睡眠唤醒和更大范围的应用输入测试仍待进行。本轮只主动停止了 AgentLink 服务，没有重启整台 Windows，也没有关闭用户原本打开的未保存文档。

IP 自动发现尚未实现。获知新地址后，可通过 CLI `computer reconnect` 验证身份并更新地址，保留备份；原生查看器需要重新打开。

尚未提供签名公证安装包、完整升级回退界面和存储配额。当前文件版本保护不是 Windows 全局文件锁，远程 Shell 也不是完整沙箱。

## 源码目录用途

| 目录或文件 | 用途 |
| --- | --- |
| apps/node | Windows 执行服务、持久任务和监督进程 |
| apps/runtime | Mac 命令行、MCP、连接诊断和文件桥 |
| adapters | 文件系统与 Windows 应用操作 |
| packages | 协议和路径权限规则 |
| native | macOS 原生查看器和挂载助手 |
| scripts | 构建、安装、测试、源码导出 |
| tests | 回归测试 |
| docs/SETUP.md | 安装与配对说明 |
| docs/RELEASE-ACCEPTANCE.md | 详细测试证据和剩余关卡 |
| SECURITY.md | 权限范围和限制 |
| SOURCE-MANIFEST.json | 导出文件的 SHA-256 清单，仅导出目录包含 |

候选源码不包含私有配对口令、证书或历史运行日志。先验收，再生成最终压缩包；尚未上传 GitHub。
