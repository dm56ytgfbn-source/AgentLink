# v0.1.0-rc.7 — Windows 主动键鼠共享预览

开发中的候选版本，尚未完成两台 Windows 实体键鼠验收。公开下载仍以 Releases 实际发布的版本为准。

- Windows 主窗口可选择已配对电脑、设置本机相对位置、开始和停止共享。无需额外终端或远程桌面窗口。
- 两端通过 v2 握手声明真实操作系统。Windows 之间保留原始扫描码；Windows 与 Mac 使用原有物理按键映射。兼容旧 Mac v1 连接；Windows 发起前检查对方能力，旧接收端会提示升级。
- 一条会话支持两边实体键鼠发起跨屏，只需一端开始。v2 屏幕位置由发起端设置，可在共享时调整。
- Windows 原生输入组件增加同一桌面会话的独占保护；关闭控制进程、停止共享、心跳中断均释放本地控制。
- 原生组件按源码版本缓存到当前用户目录，避免向 Program Files 编译写入和误用旧辅助程序。旧文件保留。
- 接收共享配置可由 rc.7 服务自动加载，不必为开启接收而重启整台电脑。仅重新读取 input_share，不动态改变身份、网络或文件权限。
- Windows 设备列表不再将旧的本机误配对记录显示为其他电脑；原记录保留。

验证记录：主/Windows 构建；35 项共享、布局及打包回归通过。retained 120 项中119项通过，当前 Mac 沙箱不能创建测试钥匙串，等待云端复验。Windows 实机完成 C# 编译、显示器检查、原生失联恢复、HTTPS/v2/原生组件/控制管道停止联测（仅本地透传，无跨屏注入）。这些不等于两台 Windows 实机跨屏已通过。

仍需验收：两台 Windows 均切换修复版后，分别使用两端实体键鼠测试跨屏、按键、滚轮、多屏、断网恢复；记录完整进程内存。Windows 入站端口不可达的问题应单独诊断，升级共享代码不等于修复公司网络限制或旧后台。
