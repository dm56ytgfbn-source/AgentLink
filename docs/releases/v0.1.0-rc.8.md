# v0.1.0-rc.8 — Windows 配对列表与共享入口修复

Windows 已成功配对另一台电脑，主窗口却可能显示“已配对 0 台”，键鼠共享下拉框也为空。原因是 Windows JSON 反序列化在字典内返回 ArrayList，界面错误地将它转换成 object[]，随后把读取不到的列表当作没有配对。

- 按实际可枚举集合读取已保存设备，保留按设备 ID 排除本机、去重逻辑。不删除或重建配对数据。
- “添加电脑”中的已有设备标记为“已配对”，点击“检查连接”使用已有凭据验证，不再要求重复开放配对、重复确认。
- 配对文件读取失败和连接失败保留具体错误，不再统一显示“没有配对”或“连接未完成”。
- Windows 原生自测实际反序列化包含本机、其他设备及同名设备的注册表，验证共享目标列表。该测试随源码 CI 和安装后自测运行。

实机：Windows 本地热修复窗口已从 0 台恢复为正确的 1 台；使用已有凭据访问另一台 rc.7 Windows 成功；主窗口启动共享后显示共享中，两台机器均启动原生输入组件。实体鼠标跨屏、键盘和双向控制仍需完成用户实测，不能将组件启动等同于最终通过。

rc.8 与 rc.7 输入协议兼容。这轮更改 Windows 界面，不改变 TLS 信任、键鼠协议或防火墙设置。公开下载以实际发布的 Releases 为准。
