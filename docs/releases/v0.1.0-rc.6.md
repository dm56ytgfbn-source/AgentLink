# AgentLink 0.1.0-rc.6（候选预览）

开发中的修复版本，只有发布后的 Assets 才是正式可下载的预览安装包。

- 配对双方拒绝本机设备身份，防止误把自己保存为另一台电脑；不会自动删除历史配对。
- Windows 界面明确显示“已配对”，不再把保存记录称为实时在线连接。
- 检查窗口和后台版本是否一致，发现旧后台时给出具体提示，保留原配对。
- 发现广播随网络接口变化刷新；扫描覆盖两个默认广播周期，排除本机，并将端口/权限错误与“没有发现电脑”分开。
- 中文下载首页、新用户指南与版本台账，安装包与源码入口分开。

两台 Windows 实机、旧版升级迁移、重启/换网及完整键鼠矩阵仍需验收；未签名、未公证，不作为稳定版本发布。
