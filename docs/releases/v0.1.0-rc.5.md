# AgentLink 0.1.0-rc.5（预览版）

这是供测试的未签名安装包。Windows x64 下载 `AgentLink-Setup-0.1.0-rc.5-windows-x64.exe` 并运行；Apple Silicon Mac 下载 `AgentLink-0.1.0-rc.5-mac-arm64.dmg`，打开后把 AgentLink 拖入“应用程序”。安装后两台电脑应处于可以互相访问的局域网。

本版 Windows 安装器会配置仅允许本地子网访问的 TCP 7443 和 UDP 47823 入站规则，分别用于连接和自动发现。Windows 已在真实机器完成安装、升级后的启动、Mac 自动发现及远程命令测试。跨两台 Windows 的连接、Intel Mac 和多设备键鼠拓扑仍需测试。

安装包尚未进行代码签名或 Apple 公证，Windows SmartScreen 和 macOS Gatekeeper 可能提示风险。请仅在信任此项目且了解预览版性质时安装。键鼠共享仍需在系统权限提示中手动授权。

页面自动生成的 `Source code (zip)` / `Source code (tar.gz)` 是源码，不是安装程序；请在 **Assets** 中选择与系统对应的 `.exe` 或 `.dmg`。
